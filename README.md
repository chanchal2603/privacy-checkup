# 🔐 Privacy Checkup

Privacy Checkup is a simple web-based privacy awareness tool.

## 🎯 Purpose

It helps users review common app permissions and understand whether they should carefully consider giving those permissions.

## 🔍 Permissions Covered

- 📍 Location
- 📷 Camera
- 🎤 Microphone
- 👥 Contacts
- 🖼️ Photos / Files

## ⚙️ How It Works

1. Select the permissions you want to review.
2. Click **Check My Privacy**.
3. The tool displays privacy tips for the selected permissions.
4. It also provides a simple privacy-awareness score.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ⚠️ Disclaimer

This is a privacy-awareness tool. It does not scan a device or determine whether an application is actually safe or unsafe.
